# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within **PolyHarness**, please do NOT file a public issue.

Instead, please report security vulnerabilities directly to:
- **Email:** `shahriarahmedseam@users.noreply.github.com`
- **GitHub:** Submit a private security advisory via the repository's "Security" tab.

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept code to reproduce the issue.
- Any suggested mitigations.

We will acknowledge receipt within 48 hours and work with you to coordinate a responsible patch and disclosure.
